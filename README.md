# Komol & Riti Wedding Invitation

A responsive animated wedding invitation built with Next.js and ready for Vercel.

## Run locally

```bash
npm install
npm run dev
```

## Deploy to Vercel

1. Upload this folder to a GitHub repository.
2. Open Vercel and choose **Add New → Project**.
3. Import the repository.
4. Keep the detected framework as **Next.js** and click **Deploy**.

The date, names, venue text, and colors can be edited in `app/page.js` and `app/globals.css`.
